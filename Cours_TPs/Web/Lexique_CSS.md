# Fiche Ressource : Lexique CSS

## **Structure et Fond**

| **Propriété** | **Description** | **Exemple de valeur** |
| --- | --- | --- |
| `background-image` | Définit une image de fond | `url('image.jpg')` |
| `background-size` | Taille de l'image de fond | `cover` (remplit tout) |
| `width` / `height` | Largeur et Hauteur | `400px`, `100%` |
| `padding` | Espace à l'**intérieur** de l'élément | `10px` |
| `margin` | Espace à l'**extérieur** de l'élément | `0 auto` (centrage) |

## **Le Texte (Typographie)**

| **Propriété** | **Description** | **Exemple de valeur** |
| --- | --- | --- |
| `font-family` | Choix de la police | `'Ewert'`, `'Arial'`, `serif` |
| `font-size` | Taille du texte | `12pt`, `24px`, `1.5em` |
| `color` | Couleur du texte | `red`, `#291200` |
| `text-align` | Alignement horizontal | `center`, `left`, `right` |
| `font-style` | Style (normal ou italique) | `italic` |
| `font-weight` | Épaisseur (gras ou non) | `bold`, `normal` |
| `text-decoration` | Décoration (souligné...) | `underline`, `none` |
| `text-decoration-style` | Décoration supplémentaire
(double l’effet decoration) | `double` |

## **Effets Visuels**

| **Propriété** | **Description** | **Exemple de valeur** |
| --- | --- | --- |
| `border` | Dessine une bordure | `2px solid black` |
| `box-shadow` | Ajoute une ombre | `2px 2px 5px #000` |
| `filter` | Ajoute un effet visuel | `sepia(50%)`, `blur(2px)` |

### Couleur

En CSS, les couleurs peuvent être écrites par leur nom (`red`) ou par leur code hexadécimal (`#291200`). N'oubliez jamais le point-virgule `;` à la fin de chaque règle !
